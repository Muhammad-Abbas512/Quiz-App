# 📝 Simple Quiz Web App

A clean and interactive **quiz web application** designed to test users’ knowledge on various topics.  

This project focuses on creating **multiple-choice quizzes**, tracking correct answers, and providing instant feedback.

## 📖 About the Project

The **Simple Quiz** app allows users to answer multiple-choice questions and get immediate results.  
It demonstrates:

- Interactive front-end design  
- Multiple-choice question functionality  
- Tracking correct and incorrect answers  
- Dynamic question display  

---

## ✨ Features

- ❓ Multiple-choice questions  
- ✅ Instant feedback on answers  
- ⏱️ Optional timer for each question  
- 📊 Score calculation  
- 📱 Fully responsive layout  

---

## 🛠️ Technologies Used

- **HTML5** – Semantic markup for quiz structure  
- **CSS3** – Styling, animations, and responsive design  
- **JavaScript** – Logic for question handling and scoring  
- **Git & GitHub** – Version control  


---

## 📌 Example Question

**Q1:** The number that is greater than zero is always a _________.

- A) Positive  
- B) Negative  
- C) Both  
- D) None of these  

Correct Answer: **A) Positive**
